Purple Wake Austin

A website I designed and developed from scratch for Purple Wake Austin, my wakesurfing and wakeboarding business on Lake Austin, Texas.

About the Project

As my business grew, I wanted to create a website that made it easier for customers to explore our services, learn about camps, and book lessons and events.

I built the website myself, focusing on making the booking process simple for customers while helping me manage the business more efficiently.

What I Built

* Designed and developed a multi-page website from scratch.
* Created dedicated pages for private lessons, summer camps, and group events.
* Built a mobile-friendly layout for customers.
* Developed the website’s navigation and user interface.
* Integrated booking functionality to help customers schedule lessons and events.
* Organized the website to make information easy to find.

Technologies Used

* HTML — Website structure and content
* CSS — Styling and responsive design
* GitHub — Source code and version control

What I Learned

Building this website gave me hands-on experience in web development, user experience, and creating software for a real business.

I learned how to take an idea, develop it into a working product, and improve it based on what customers needed.

Project Status

The website was developed for Purple Wake Austin and is part of the business’s customer-facing platform.
